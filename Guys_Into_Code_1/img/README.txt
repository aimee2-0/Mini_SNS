Put your test images here so LoadTestImages can load them into the database.
Both .png and .jpg are supported (.png is checked first).

  profile/  - 10 images:  1.png, 2.png, ... 10.png  (or .jpg)
  qa/       - 12 images:  1.png, 2.png, ... 12.png  (or .jpg)
  sns/      - 10 images:  1.png, 2.png, ... 10.png  (or .jpg)

After placing the files, run the SQL script then the Java loader (see RUN_STEPS.md).
